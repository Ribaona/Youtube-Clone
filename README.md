## ✨ Features
 
### Base Features
- ✅ Fully structured YouTube homepage layout
- ✅ Sticky navbar with logo, search bar, and icons
- ✅ Sidebar with categories and footer links
- ✅ Video grid with thumbnails, channel info, views and dates
- ✅ Responsive design for mobile, tablet, and desktop
### Custom Features
- 🌙 **Dark Mode Toggle** — A CSS-only dark mode switch using a hidden checkbox trick. No JavaScript required.
- 🎥 **Hover Preview** — Hovering over a video thumbnail triggers a smooth zoom effect and reveals an info overlay with the video title and channel name.
- 🏷️ **Category Filter Chips** — A horizontal row of clickable category chips below the navbar that highlight on selection (built with Cursor).
- 📺 **Video Watch Page** — Clicking a video opens a dedicated watch page with an embedded video player, video details, recommended videos sidebar, and comments section (built with Cursor).

## 📱 Responsive Design
 
| Screen Size | Layout |
|-------------|--------|
| Desktop (1024px+) | Full sidebar + 4 column video grid |
| Tablet (768px - 1024px) | Narrow sidebar + 2 column video grid |
| Mobile (below 768px) | No sidebar + 2 column video grid |

## 🚀 Getting Started
 
### Prerequisites
Just a modern web browser — no installs needed!
 
### Installation
 
1. Clone the repository:
```bash
git clone https://github.com/your-username/youtube-clone.git
```
 
2. Navigate into the project folder:
```bash
cd youtube-clone
```
 
3. Open `index.html` in your browser:
```bash
open index.html
```
Or simply double-click `index.html` in your file explorer.
